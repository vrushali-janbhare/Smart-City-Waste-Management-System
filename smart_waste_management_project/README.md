# City Garbage Management System

## Project Overview
The City Garbage Management System is a web-based application designed to improve and simplify waste management activities in a city. It aims to manage garbage collection, citizen complaints, collection schedules, vehicles, and waste collection records efficiently.

## Technologies Used

**Backend:**
- Java
- Spring Boot
- Spring Data JPA
- Hibernate

**Database:**
- MySQL

**Frontend:**
- HTML5
- CSS3
- JavaScript

## Database Management
MySQL is used to store and manage application data, including user details, area information, vehicle details, complaints, collection schedules, and collection records.

## Key Features (Planned)
- **User Management:** Manage citizen and administrator information.
- **Area Management:** Maintain city areas and their details.
- **Vehicle Management:** Manage garbage collection vehicles.
- **Waste Collection Scheduling:** Create and manage waste collection schedules.
- **Complaint Management:** Allow citizens to register and track garbage-related complaints.
- **Collection Records:** Maintain records of completed waste collection activities.

## Project Development Status
Currently, the project is in the database design and development phase. Database table structures and JPA entity mappings are being implemented using Spring Data JPA and Hibernate.

## Project Objective
To develop an efficient and organized digital platform that helps improve city cleanliness, streamline garbage collection activities, and support better waste management.
